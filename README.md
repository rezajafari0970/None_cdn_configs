# None CDN Config Collector

Panel-driven modular collector for fetching subscription sources,
filtering CDN-backed configurations, managing TTL, and publishing
non-CDN configurations.

## Core principles

- Fully panel-driven
- Modular architecture
- Independent from other server projects
- Continuous fetch workers
- Automatic recovery
- Per-source fetch interval
- Per-source config lifetime
- Last-seen TTL refresh
- CDN / Direct classification
- Full audit trail
- Git-based source history
